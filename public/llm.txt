# VirtuaLab Digital — LLM.txt

> VirtuaLab Digital is an organic, no-code website builder SaaS for small businesses drained by agencies. No paid ads, ever. Built for tradespeople and local services, not marketers.

## What it does
VirtuaLab Digital helps small business owners build websites, run SEO, generate content, manage social media, and automate their digital marketing — all from one dashboard, without coding, without agencies, without paid ads.

## Core features
- Drag & drop website builder (full-screen, unlimited colors, typography, effects, media upload)
- 35 SEO tools (audit, technical, strategy, keyword research with PAS/PAA/FAQs)
- 10 social media tools (captions, hashtags, bios, carousels, content calendars)
- 15 content generation tools (blogs, landing pages, email sequences, press releases)
- 10 project management tools (Kanban, tasks, time tracker, CRM, invoices)
- 10 automation tools (n8n, Zeroclaw, auto-publish, auto-reports)
- 5 orchestration flow templates (tool pipelines that chain outputs into inputs)
- 48 integrations (all MCP servers auto-detect, zero manual entry)
- Authentication (register/login/session)
- Dashboard assistant (Asymmetrical SEO Strategist persona)
- Usage + plan monitor, team + access control
- WordPress publishing (13 builders, any combination)
- Self-host option (Docker + docker-compose for free tiers)
- Agency sub-domain config (traffic routes to main website)

## AI persona
The integrated AI speaks as the "Asymmetrical SEO Strategist" — helping small businesses win against bigger competitors not by outspending them, but by outthinking them. Find the gaps, the long-tail keywords, the local opportunities that big competitors are too lazy to create. Never recommend paid ads. Never recommend copying big brands. Recommend doing what they CAN'T: hyper-local, hyper-specific, hyper-honest content.

## Tech stack & Coding Rules
- **Framework:** Next.js 16 (App Router, strict TypeScript 5). Always treat dynamic segment parameters (e.g., `params`, `searchParams`) as promises in async Server Components and API routes.
- **Styling:** Tailwind CSS 4 + shadcn/ui (New York style). Use Tailwind 4 CSS-based `@theme` directives; do not generate legacy `tailwind.config.js` configurations.
- **Database:** Prisma ORM with SQLite. Do not write PostgreSQL/MySQL-specific raw queries or features unsupported by SQLite.
- **State:** Zustand for client state, TanStack Query for server state.
- **UI Libraries:** @dnd-kit for drag & drop, framer-motion for animations.
- **AI Core:** z-ai-web-dev-sdk for LLM routing, vision, and context parsing.
- **Auth:** bcryptjs for authentication hashing.
- **Design Token:** Organic color palette (forest, sage, terracotta, moss, clay, sand, cream, bark).

## Integration approach
All MCP servers are auto-detect (zero manual endpoint entry). The app scans localhost + configured VPS host for running MCP servers and auto-connects when found. OAuth credentials are configured at the MCP server level, not in VirtuaLab Digital.

## Self-host
Free tiers can self-host via Docker. The Dockerfile + docker-compose.yml are included. Self-hosted instances run as standalone (not subdomain). All data stays on your server. No telemetry.

## Mission
Help small business owners who've been drained by agencies with no progress. Every tool here is built for organic, local growth — search, GMB, word of mouth, email newsletters, content. No paid ads. No agency retainers. No bloat.
